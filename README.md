# arecanut-harvesting-robot
An autonomous/semi-autonomous robotic system designed for climbing arecanut trees and automated harvesting, powered by Raspberry Pi 5 and ESP32.
Arecanut Harvesting Robot
An innovative agricultural robotics project aimed at automating the labor-intensive process of harvesting arecanuts (betel nuts). This system features a custom-built climbing mechanism and a specialized robotic arm to navigate the unique challenges of plantation environments.

Key Technical Features:

Core Controller: Raspberry Pi 5 (8GB) for high-level processing and computer vision.

Actuation: Multi-motor drive system utilizing high-torque planetary and wiper motors for vertical climbing.

Vision System: Integrated Pi Camera v1.3 for real-time monitoring and target identification.

Robotic Arm: A custom telescopic arm design equipped with a precision cutting mechanism for efficient harvesting.

Wireless Control: ESP32-based sub-systems for low-level motor control and sensor data acquisition.
